# 下班生活助手

用 Windows 或 iPhone 记录下班后的时间投入。选择英语口语、技术学习、运动、阅读等活动开始计时，也可以手动补记。每周统计按北京时间汇总，活动附带的完成事项、心得和下一步计划可以随时回看。

[打开下班生活助手](https://adson321.github.io/evening-life-assistant/)

## 开始使用

Windows 用 Edge 或 Chrome 打开网页。iPhone 用 Safari 打开同一网址，点「分享 → 添加到主屏幕」。如需从快捷指令启动，在「快捷指令」中新建一项，添加「打开 URL」，填入上面的网页地址。

选一项活动开始计时，结束时填写实际分钟数和心得。旧版网页中的记录可在原浏览器导出 JSON，再在新网页的数据管理页导入。迁移前先结束正在进行的计时。

## 在两台设备之间同步

1. 在自己的 GitHub 账号下准备一个专用的 **Private** 仓库，例如 `evening-life-data`，创建时勾选添加 README，建立默认分支。
2. 在 GitHub 的 **Settings → Developer settings → Personal access tokens → Fine-grained tokens** 中生成令牌。选择 **Only select repositories**，仅勾选上述私有仓库，授予 **Contents: Read and write**。两台设备可以使用独立令牌。
3. 在有原始记录的设备上打开网页的数据管理页，填入完整仓库名和令牌，点「连接并同步」。看到「已同步」后，在另一台设备连接同一私有仓库。
4. 在 Windows 补记一条活动，切到数据管理页完成同步。在 iPhone 点同步并查看历史记录，再从 iPhone 编辑这条活动并在 Windows 核对。

在私人设备上勾选「在此设备记住连接」并完成同步后，再次打开同一入口会自动连接。令牌保存在该浏览器的网站数据中，点「断开」可移除。未勾选时仅在当前标签页会话中保存。iPhone 建议固定使用 Safari 普通标签页或主屏幕图标中的一个入口。页面在保存、回到前台以及使用期间约每分钟尝试同步。编辑活动或心得时暂缓自动同步，保存后切到其他标签即可继续。离线记录在本机保留，两端对同一条记录的冲突可在手动同步时选择。跨设备接续计时前请先同步。

活动、计时、每日心得和周复盘保存在私有仓库的 `evening-life.json`。删除会随同步传播，旧版本仍在该私有仓库的提交历史中。公开 Pages 仓库只需要网页文件。请勿上传个人 JSON 备份或令牌。可随时导出 JSON 备份或 CSV 统计表。

## 部署

将本仓库根目录文件放入默认分支。在 **Settings → Pages → Deploy from a branch** 选择默认分支和 **/(root)**，保存并等待 Pages 部署完成。项目使用原生 HTML 和 JavaScript，无需构建。首次在线打开后，支持 Service Worker 的浏览器会缓存页面供离线使用。
