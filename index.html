设备同步

连接 GitHub 私有数据仓库，在 Windows 和 iPhone 上接续记录。

数据管理与备份

记录保存在当前设备，连接同步后也会保存到指定的私有仓库。为避免 iPhone 清理浏览器数据或更换设备造成丢失，建议每周导出 JSON 备份到 iCloud Drive。

数据说明

计时基于实际开始与暂停时间；切换 App、锁屏后仍按时间戳计算。活动结束前若清除浏览器数据，当前计时可能丢失。手机的“文件”预览或部分浏览器私密模式可能不持久保存数据，建议通过 Safari 使用并定期备份。

如何放到 iPhone 主屏幕

若页面通过 Safari 中可访问的网页地址打开，点「分享」→「添加到主屏幕」，即可像 App 一样启动。直接打开本地 HTML 文件时，这项功能可能不可用；在 Windows 上可将文件部署到自己的 HTTPS 静态网站。

此工具是可运行的网页应用，不是经过苹果签名的原生快捷指令，也不会自动写入日历。记录和统计均在本地完成。
